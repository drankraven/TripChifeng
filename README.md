# 昌图出发 · 通辽赤峰 5 天自驾环线

昌图往返通辽、扎鲁特、辽上京、赤峰、宝古图、奈曼、库伦的 **5 天 4 晚油车自驾环线** 路书。含高德 API 实测车程、星图云地图底图、住宿餐饮与加油建议。

## 路线概览

昌图 → 大青沟 → 通辽 → 哈神加游乐场 → 扎鲁特山地草原 → 林东（辽上京、召庙）→ 赤峰 → 响水荷花池 → 宝古图沙漠 → 奈曼 → 库伦 → 昌图。

- 全程约 **1,855 km / 26 h**（高德 API 按完整途经点实测）
- 过路费约 **¥318**
- 四晚住宿：通辽、林东、赤峰、奈曼

## 核心景点

大青沟、通辽市区、哈神加游乐场、扎鲁特山地草原、辽上京、召庙、赤峰市区、响水荷花池、宝古图沙漠、奈曼王府、库伦三大寺、中国安代博物馆。
