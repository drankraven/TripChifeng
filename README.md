# TripChifeng · v8

巴林左旗出发，4天3晚纯电自驾。v8核心：D2精简早到 + D3轻松人文。

## 路线概览

| 天 | 日期 | 行程 | 驾驶 | 到酒店 |
|---|------|------|------|------|
| D1 | 7.7 周二 | 林东→真寂之寺→辽上京博物馆→遗址→经棚补能→达里湖 | 254km | ~18:30 |
| D2 | 7.8 周三 | 达里湖日出→达达线精简→石林快览→热阿线黄岗梁→经棚 | 225km | **15:20** |

**总计：~1040km**

## v8 核心改动

### D2 精简（解决太赶问题）
- 利用达里湖日出（04:50）天然早起
- 达达线停靠从 4 个减到 2 个（白音敖包+风车）
- 石林从 1.5h 减到 45min（一园区精华够了）
- **15:20 到经棚**（比 v7 早近 1 小时）

### D3 补偿（平衡行程）
- 经棚早市逛逛买特产
- 乌丹镇中途午餐休息
- 下午赤峰博物馆 + 红山落日
- 自然→人文完整转换
