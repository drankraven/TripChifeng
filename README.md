# TripChifeng

从巴林左旗出发，游览赤峰境内辽上京、达达线（贡格尔草原/达里诺尔湖/阿斯哈图石林）、热水塘温泉、热阿线黄岗梁、乌兰布统草原，7 月 7 日周二至 7 月 10 日周五中午返回沈阳的纯电自驾旅行路书。

当前版本重点：

- 起点改为巴林左旗（已在当地），终点回到沈阳，全程在赤峰境内游览。
- 4 天 3 晚：D1 巴林左旗→克什克腾经棚，D2 达达线(贡格尔草原/达里诺尔湖/阿斯哈图石林)→热水塘温泉过夜，D3 热阿线黄岗梁→乌兰布统草原，D4 经围场/承德返沈阳（周五中午到）。
- 已加入热水塘温泉过夜，并把达达线 + 热阿线两大景观大道的精华全部串上。
- 每天预留午餐、晚餐时间，并逐段标出景点间自驾距离与用时。
- 地图改为本地 SVG 经纬度示意图，不依赖在线瓦片，避免地图缺失。

本地预览可以直接打开 `index.html`。
