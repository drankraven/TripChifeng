# TripChifeng · v7

巴林左旗出发，4天3晚纯电自驾：真寂之寺 → 辽上京 → 达里湖落日 → 达达线 → 热阿线 → 赤峰市 → 沈阳。去温泉减回头路。

## 路线概览

| 天 | 日期 | 行程 | 驾驶 |
|---|------|------|------|
| D1 | 7.7 周二 | 林东→真寂之寺→辽上京博物馆→遗址→经棚补能→达里湖落日 | 254km |
| D2 | 7.8 周三 | 达里湖→达达线全程→阿斯哈图石林→热阿线黄岗梁→经棚 | 225km |
| D3 | 7.9 周四 | 经棚→赤峰市（辽代历史文化博物馆+红山公园） | 280km |
| D4 | 7.10 周五 | 赤峰→沈阳（中午到） | 280km |

**总计：~1040km**

## v7 核心改动

- **去掉热水塘温泉住宿**：省 28km 回头路，D2 终点落在经棚（酒店品质好 + 充电方便）
- **线性推进无重复路**：每天只往一个方向走，不再围着经棚绕圈
- **D1 住达里湖边**：傍晚看落日，D2 早上直接上达达线
- **D3 半天到赤峰**：不再赶路，下午逛博物馆 + 红山公园
- **交互地图 + POI**：Leaflet + 星图云底图，路线节点 + 14 个 POI 标记（充电桩⚡/酒店🏨/餐饮🍽️）

## 技术栈

- 纯静态 HTML/CSS/JS，无构建步骤
- Leaflet.js 交互地图
- 星图云 (GeoVis Earth) 矢量瓦片底图
- GitHub Pages 部署
